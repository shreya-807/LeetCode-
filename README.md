# 🌟 Easy LeetCode Solutions in Java & C++

Welcome to my repository of **easy-to-understand solutions** for LeetCode problems.  
This repo is designed to help learners, interview-prep candidates, and developers quickly grasp problem-solving techniques with **clean code** in both **Java** and **C++**.

---

## ✨ Features
- 📘 Solutions to frequently asked LeetCode problems  
- 💻 Implemented in **Java** and **C++**  
- 🧩 Focus on **clarity and simplicity**  
- 📚 Covers a wide range of topics:
  - Arrays & Strings  
  - Hashing & Maps  
  - Stacks & Queues  
  - Linked Lists  
  - Trees & Graphs  
  - Dynamic Programming  
  - Bit Manipulation  
  - Greedy & Backtracking  

---

## 🛠️ Languages Used
- **Java** → Beginner-friendly, widely used in interviews  
- **C++** → Fast execution, STL-powered solutions
